# 12 — API Contract (v1, proposed)

Base: `/api/v1` (same origin via Pages Function proxy). Machine-readable
schema generated by `drf-spectacular` at `/api/v1/schema/` (Swagger UI at
`/api/v1/docs/`, staff-only in production). This doc is the human summary;
the generated schema wins on conflicts.

## Conventions

- JSON, `snake_case`. Timestamps ISO-8601 UTC; clients render in org timezone.
- Auth: Django session cookie (`HttpOnly; Secure; SameSite=Lax`). Unsafe methods require `X-CSRFToken` (from `GET /auth/csrf`).
- Pagination: `?page=&page_size=` (max 100) → `{count, next, previous, results}`. Audit log uses cursor pagination.
- Filtering `?field=value`, search `?q=`, sort `?ordering=-starts_at`.
- Errors: `{ "error": { "code": "permission_denied", "message": "...", "fields": {"title": ["required"]} } }`.

| Status | Meaning |
|---|---|
| 400 | validation | 401 not signed in | 403 signed in, lacks permission | 404 not found **or not visible** (avoid leaking existence) | 409 illegal workflow transition / conflict | 429 rate-limited |

## Endpoints (by module)

**Public (no auth, cacheable, published data only)**
`GET /public/snapshot` (everything the prerender needs) ·
`GET /public/events[/:slug]` · `/public/blogs[/:slug]` · `/public/speakers` ·
`/public/initiatives` · `/public/team` · `/public/gallery` · `/public/pages/:key`

**Auth** — `POST /auth/login` (rate-limited 5/min/IP+email) · `POST /auth/logout` ·
`GET /auth/me` (user + effective permissions with scopes, for UI hints) ·
`POST /auth/password/forgot` (always 202 — no account oracle, as in Control Room) ·
`POST /auth/password/reset` · `POST /auth/verify-email` · `POST /auth/second-factor`

**RBAC/Org** — `/users`, `/roles`, `/permissions` (read-only), `/role-assignments`,
`/verticals`, `/memberships`, `/academic-years`, `/leadership`, `/succession` (POST = run), `/approval-rules`, `/settings`

**CMS** — `/content` (list/create) · `/content/:id` · `/content/:id/versions` ·
`POST /content/:id/{submit|review|approve|request-changes|schedule|publish|unpublish|archive|rollback}` ·
`GET /content/:id/preview?version=` · `/blogs` · `/speakers` · `/block-types` (read; write = Technical)

**Events & ops** — `/events` · `/events/:id/{verticals|participants|workstreams|speakers|sponsors|media|registrations|report}` ·
`/projects` · `/workstreams` · `/tasks` (`?assigned=me`) · `/requests` (`?to_vertical=`, `?from_vertical=`) · `POST /requests/:id/transition`

**Other** — `/media` (POST returns a signed Cloudinary upload; client uploads directly, then `POST /media/confirm`) ·
`/notifications`, `POST /notifications/read` · `/kb/articles` · `/analytics/{public|internal}` · `/audit` (`audit.view`)

**Internal** — `POST /internal/tick` (header `X-Tick-Secret`, not proxied publicly — Worker calls the backend host directly)

## Permission declaration

Each view declares `required_perm` and a scope resolver; `04_PERMISSION_MATRIX.md`
is the reference. A test enumerates every URL pattern and asserts each has
a permission declaration (no accidentally open endpoints).

## Phase 1 — implemented endpoints (2026-09-25)

Base `/api/v1`, **no trailing slashes**. Every endpoint below is live in
`backend/` and described by the generated schema (`/api/v1/schema`).

| Method & path | Permission (coarse gate → scoped check) | Notes |
|---|---|---|
| `GET /auth/csrf` | public | sets `csrftoken` cookie, returns `{csrf_token}` |
| `POST /auth/login` | public, CSRF, 5/min per IP+email | `{email, password}` → `me` payload; failure **400 `invalid_credentials`** (same for unknown/wrong/inactive) |
| `POST /auth/logout` | signed in, CSRF | 204 |
| `GET /auth/me` | signed in | `{user, permissions:[{permission, scope_type, scope_id, own_only}], organization:{name, timezone}}` |
| `POST /auth/password/forgot` | public, CSRF, 5/hour per IP | always **202** with the same body |
| `POST /auth/password/reset` | public, CSRF, 10/hour per IP | `{uid, token, new_password}`; bad/expired → **400 `invalid_token`**; ends all sessions |
| `GET/POST /users` | `user.view` (scoped) / `user.manage` (global) | POST `{email, full_name, send_invite}` |
| `GET/PATCH /users/{id}` | `user.view` / `user.manage` | out of scope → 404 |
| `POST /users/{id}/deactivate`, `/reactivate` | `user.manage`; privileged targets need `role.manage` | self → 403; last Super Admin → 409 |
| `GET /permissions` | `permission.view` | |
| `GET /roles` | `role.view` | read-only in Phase 1 |
| `GET/POST /role-assignments` | `role.view` (scoped) / role's `assign_permission` at target scope | filters `active, user_id, scope_id, role` |
| `POST /role-assignments/{id}/revoke` | same as assigning | `{reason}`; last Super Admin → 409 |
| `GET/POST /verticals` | `vertical.view` (scoped) / `vertical.manage` (global) | `?include_archived=true` |
| `GET/PATCH /verticals/{id}` | `vertical.view` / `vertical.manage` | |
| `POST /verticals/{id}/archive` | `vertical.manage` | `{confirm: <slug>}`; live assignments → 409 |
| `GET/POST /academic-years` | signed in / `academic_year.manage` | |
| `POST /academic-years/{id}/make-current` | `academic_year.manage` | |
| `GET/POST /memberships` | `membership.view` / `membership.manage` on the vertical | defaults to current year |
| `POST /memberships/{id}/end` | `membership.manage` | row kept |
| `GET /audit` | `audit.view` (global) | cursor pagination; filters `action` (prefix), `actor_id`, `actor_email`, `result`, `target_type`, `target_id`, `since`, `until`, `q` |
| `GET/PATCH /settings` | `system.settings` | `{name, timezone}` |
| `GET /schema`, `GET /docs` | dev: public; otherwise signed in | generated OpenAPI + Swagger UI |

Contract clarifications made during implementation: a duplicate unique field
(e.g. vertical slug, user email) is a **400 field error**, not 409; 409 is
reserved for state conflicts (last Super Admin, already archived/revoked/ended,
live assignments). Refused mutations write a `DENIED` audit row.
